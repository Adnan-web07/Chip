Att ge sidan liv

HTML är skelettet, men CSS är huden och kläderna. Här förklarar jag hur färger och formulär fungerar i modern webbdesign.

Färger på tre olika sätt

I CSS kan man ange färger på flera olika sätt, vilket är ett krav för högre betyg:

  • Hexadecimalt: #1a1a1a
  • RGB/RGBA: rgba(0, 0, 0, 0.05)
  • HSL/HSLA: hsl(0, 100%, 40%)
