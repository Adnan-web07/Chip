Att ge sidan liv

HTML är skelettet, men CSS är huden och kläderna. Här lär vi oss hur färg och struktur fungerar på en webbplats.

Färger på tre sätt

I CSS kan vi ange färgkoder på olika sätt beroende på vad som passar bäst:

  • Hexadecimalt: #1a1a1a
  • RGB: rgb(255, 0, 0)
  • HSL: hsl(120, 100%, 25%)

Layout med Grid

Med CSS Grid delar vi upp hemsidan i zoner. Den här sidan använder grid för att placera header, meny, main och footer på rätt plats.
