CSS Magic: Låt oss göra det snyggt!

Att ge sidan liv

HTML är skelettet, men CSS är huden och kläderna. Här ska vi lära oss hur vi kan få vår sida att se ut som ett mörkt och spännande textbaserat äventyr!

Färger på tre olika sätt

I CSS kan man ange färger på flera olika sätt. En bra webbutvecklare har koll på alla:

  • Hexadecimalt: #1a1a1a (Perfekt för en mörkgrå bakgrund)
  • RGB/RGBA: rgba(255, 0, 0, 0.8) (En lite genomskinlig, blodröd färg)
  • HSL/HSLA: hsl(120, 100%, 25%) (En mystisk, giftig grön färg)

Interaktivitet med Pseudo-klasser

För att få en länk eller knapp att reagera när man drar musen över den använder vi selektorn :hover. CSS gör att webben känns levande!
