Färghantering i CSS

Vi kan definiera färger på flera olika sätt beroende på hur mycket kontroll vi vill ha över nyanserna:

  • Hexadecimalt system: Perfekt för statiska basfärger som #1a1a1a.
  • RGB system: Anger mängden Rött, Grönt och Blått mellan 0 och 255.
  • HSL system: Hanterar färgton, mättnad och ljusstyrka vilket gör det lättare att skapa harmoniska färgskalor.

Sidans Layout
